About Summerwave

Summerwave is a package manager for macOS, built to distribute the command-line tools that macOS software developers rely on. Its project, LinuxWave, covers Linux.

Why Summerwave

  • Small on disk. The installer fetches individual files rather than cloning the repository, and there is no package cache to keep in sync.
  • One command per package. Common tools are installed by name, without hunting for release pages.
  • Versioned by design. Every binary lives under package@version, so several versions coexist and none of them shadow a system tool.
  • Optional unversioned links. wave link <package> creates a plain package shortcut that points at the highest installed version and re-points itself whenever versions are installed or removed.
  • Isolated by construction. Everything Summerwave installs stays inside its own directories; it never overwrites or links against macOS system libraries, so even a major macOS upgrade leaves it intact.
  • No stale metadata. Package data is read from the SummerwaveOrg/SeaLane repository at request time.
  • Checksum before extraction. A package whose SHA256 is missing or does not match is refused, never installed with a warning.
  • Resumable downloads. An interrupted transfer continues with -C.
  • Transparent implementation. Python and Shell only. The interpreter is bundled, so no runtime has to be installed and no behaviour is hidden behind one.
  • Dependencies handled for you. Packages that need libraries declare them; Summerwave installs, tracks and removes those libraries by reference count.

Supported macOS Version

Intel: macOS Monterey 12 and above
Apple Silicon: macOS Sequoia 15 and above

Install Summerwave

In the terminal, run: 

$ /bin/bash -c "$(curl -fsSL https://github.com/SummerwaveOrg/Summerwave/releases/latest/download/install.sh)"

(If you are using bash instead of zsh, run source ~/.bashrc)

We recommend reading the handbook after installing. Read it here.

Requirements: Intel — macOS Monterey 12 or later; Apple Silicon — macOS Sequoia 15 or later; Xcode Command Line Tools.
You do not need to install Python — Summerwave bundles its own interpreter.

This repository holds source, not an installation. Running wave from inside a clone, or adding directories from the clone to PATH, fails by design.

Uninstall Summerwave

To completely remove Summerwave from your system, run the following command in your terminal: 

$ /bin/bash -c "$(curl -fsSL https://github.com/SummerwaveOrg/Summerwave/releases/latest/download/uninstall.sh)"

uninstall.sh is scriptable: --force skips the confirmation, which otherwise needs a terminal (use --force in CI): 

$ /bin/bash -c "$(curl -fsSL https://github.com/SummerwaveOrg/Summerwave/releases/latest/download/uninstall.sh)" -- --force

Download Directory

macOS: /opt/macwave
Linux: /home/linuxwave/.linuxwave

Install Packages

One command downloads, verifies, unpacks and links a package — and checks its SHA256 before anything is installed: 

$ wave install ffmpeg

Not sure of the name? wave search <keyword> searches the index and wave info <package> shows the detail. There is no silent replacement: the version you ask for is the version you get, so pinning is wave install ffmpeg@6.0.

Symlink Management

Since Summerwave 2.4, once a versionless link exists, Summerwave keeps it pointing at the right version on its own:

  1. If the highest version is uninstalled, the versionless link moves to the highest version that remains, and the uninstalled version's own link goes with it.
  2. An install re-points the versionless link at the version it just installed; add --no-link to that install to skip this.
  3. If a package has no versions left at all, the versionless link is removed.
  4. A versioned name is always callable, whether or not a versionless link exists.

A manual wave unlink {package_name} is remembered: a later uninstall will not re-create the link for that package.
